Which box is the coffee maker in?

A box inventory answers that in seconds. Here's how to keep one you'll actually keep up, from the first box to the last one unpacked.

How to keep track of moving boxes

  1. Number every box by room. KIT-01 for the kitchen, BED-02 for a bedroom, LIV-03 for the living room. The room tells the movers where it goes; the number tells you which box it is. Write it on two sides and the top.
  2. Take one photo before you tape it. You don't have to type out every fork. The photo shows what's in it.
  3. Write the few words you'll search for later. "Coffee maker, mugs, filters." Think about what you'll look for on the first morning, not everything in the box.
  4. Mark the ones that matter. Fragile, heavy, open first, and the things that ride with you instead of the truck: medicine, papers, chargers and keys.
  5. Tick each box as it moves. Loaded, delivered, unpacked. If one doesn't arrive, you know which one and what was in it.

Pack it so it's easy to find again

  • Heavy things go in small boxes: books, tools, canned food. Light things go in big ones: pillows, lampshades, towels.
  • One room per box, so it can go straight to the right room in the new place.
  • Pack an open-first box for each person: sheets, a towel, a mug, the phone charger, tomorrow's clothes.
  • If movers make their own inventory, check it against yours, and note any damaged box on it before you sign at delivery.

Questions people ask

How do I keep track of what's in my moving boxes?

Give each box a number by room, take one photo of the inside before you seal it, and write a few words you'd search for later. Keep the list on your phone so you can search it on moving day.

Do I have to list every item in a box?

No. One photo and a few search words, like "coffee maker, mugs, filters", are enough to find a box later. List single items only when they're valuable.

What should I write on a moving box?

The room it goes to and its number, such as KIT-07, on two sides and the top, plus FRAGILE or THIS SIDE UP when it's true. Keep what's inside off the outside if it's valuable.

How do I find a box after the move?

Search your list for the thing you need. The number tells you which box, and the room code tells you where it was put.
