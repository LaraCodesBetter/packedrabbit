Boxes first, then the big things, then the move

The app teaches one thing at a time, in the order you'd pack. The bar along the bottom shows what the next step earns, then gains a tab each time something is learned.

  1. Boxes. "Your first box. Pack it. Photograph it. Find it." with the empty box waiting. Then which room it's from, starting in the easiest one. After the first box, the Boxes tab appears. Then: pack another box, or something won't fit in a box.
  2. The price, once. The bar never shows it. It appears only when someone wants a fourth box, after they've seen what they built.
  3. Then how to use it. Adding a box, finding one, and saying it out loud.
  4. Big Stuff. One list of the big things: select all that apply. Then each one gets its room and the question a mover asks (bed size, drawers, sofa size, screen size, rug size), on one screen, remembering the last room. Then "Taking any of these too?" for what people forget. At the end: the cubic feet and the truck size.
  5. Not coming. Donating? Selling? Not sure? A yes to "Do you need help with that?" opens the tool right there. Then the Sorting tab appears.
  6. The move. The date, the mover, the new place. Then the Moving tab appears.
  7. Everything else comes as "Did you know?", one at a time, then Menu.

Box sizes are just Extra small to Extra large, or Custom, regular or heavy duty. The box brand is optional and remembered for the next box. The real dimensions are worked out behind the scenes and shown only if you tap. The math uses the biggest box of each size any store sells, so the truck is never underestimated.
